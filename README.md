# WISP 无线上网

TUF 小旋风 Pro（TUF-BE6500）在本项目使用的 57143 KoolCenter 固件界面中没有可直接开启的 WISP 模式。这套方案用 **2.4 GHz 无线接口模拟无线 WAN**。路由器通过 Wi-Fi 连接上级热点，接在本机 LAN 口或连上本机热点的设备都能借这条链路上网。

**安装前请先确认路由器已经具备可用的 WISP 开机恢复脚本和无线配置。** 这个插件提供软件中心控制页。刚刷好固件的路由器缺少这套环境时，安装器会提示「缺少已有 WISP 配置」并退出。

## 实现方法

1. **同一块 2.4 GHz 无线电同时做热点和客户端。** 路由器保持「无线路由器模式」。已有开机脚本在 2.4 GHz 无线电（`phy1`）上保留本机热点（AP），另建一个客户端接口（STA，实测名为 `wisp_sta4`）连接上级 Wi-Fi。两个接口共用一个信道，所以切换上级网络时，本机 2.4 GHz 热点也要跟着换信道。
2. **客户端接口承担 WAN 出口。** 开机脚本用 `wpa_supplicant` 完成 WPA2 认证，再由 `udhcpc` 向上级获取 IPv4 地址、网关和 DNS。无线客户端接口独立于 LAN 网桥。路由器把内网设备的上网流量经默认路由转发到该接口，并用 NAT 将源地址转换为上级分配给路由器的地址。下游设备继续使用本机的内网地址。
3. **控制页管理这条连接。** 模块 `wispcontrol` 用 `ath0` 扫描附近的上级 Wi-Fi。用户确认切换后，后台保存上一份配置，写入所选网络和信道，再重启，由已有开机脚本按新配置连接。页面分别检查无线认证状态和默认路由，因此能提示「已连接 Wi-Fi，但缺少上网路由」。

## 适用环境

| 项目 | 要求 |
| --- | --- |
| 机型与固件 | TUF-BE6500（TUF 小旋风 Pro WiFi 7），IPQ64。已有实机验证记录的固件为 `3.0.0.6.102_57143_koolcenter`，软件中心为 1.9.63。 |
| 工作模式 | 无线路由器模式，LAN 地址 `192.168.50.1/24`。上级 Wi-Fi 使用不同网段。 |
| 上级 Wi-Fi | 2.4 GHz，信道 1–13，WPA2-Personal（PSK / CCMP），密码为 8–63 个可打印 ASCII 字符。 |
| 已有配置 | 新命名使用 `/jffs/wispcontrol/wpa.conf`、可执行的 `/jffs/wispcontrol/restore.sh` 及与其配套的开机环境。无线控制套接字目录为 `/tmp/wispcontrol/ctrl`。控制页依赖固件提供的 `jq`、`iw`、`wpa_cli`、`flock`、`nvram` 及软件中心接口。 |

## 安装与使用

1. 从 [GitHub Releases](https://github.com/CrayonL/wispcontrol/releases/latest) 下载附件 `wispcontrol.tar.gz`。
2. 登录路由器后台，在「软件中心 → 手动安装」上传该文件。安装完成后，从「已安装 → WISP 无线上网」打开控制页。
3. 点击「扫描附近 Wi-Fi」，选择网络、输入密码，核对信道后确认连接。打开页面、读取状态和扫描均可在当前连接下操作。确认切换、恢复、启用或停用后，路由器会保存配置并重启，通常需要约 1–2 分钟。
4. 如果新网络连不上，通过 LAN 口或本机热点重新打开控制页，点击「恢复上一份 Wi-Fi 并重启」。每次切换保留紧邻的上一份配置。若上级后来更换信道，需要重新扫描并应用。

当前发行版为 **v0.0.1**。已安装 v1.0.3 或 v1.0.4 的用户如需切换版本，可在「手动安装」页覆盖安装。覆盖安装会沿用现有 WISP 配置和套接字。若新旧配置目录同时独立存在，插件会提示先确认使用哪一套。卸载清理控制页、脚本和软件中心登记，设备上已有的联网配置、密码和启停状态会保留。

## 构建与验证

在 Linux 下从仓库根目录运行。打包工具来自 [rogsoft 的 build.py](https://github.com/koolshare/rogsoft/blob/f2181f4528369336382a91cec458a05371b18de3/build.py)。

```sh
python3 build.py --platform ipq64
node tests/test_control.js
timeout 60 busybox sh tests/test_control.sh
sha256sum wispcontrol.tar.gz
```

| 验证环境 | 已检查的行为 |
| --- | --- |
| TUF-BE6500 真机，v1.0.3 | 登录后打开控制页、读取无线状态、扫描、输入校验以及返回软件中心。 |
| 隔离的 Linux / BusyBox 环境，v0.0.1 | 实际执行安装、从 v1.0.3 和 v1.0.4 覆盖安装、卸载和重装，检查版本登记、原配置、禁用标记和重启等待标记。错误机型、缺少 WISP 配置、两套配置冲突均会拒绝安装。固件的 NVRAM 和 DBus 在此测试中由替身提供。 |
| 控制逻辑测试 | 扫描结果、中文 SSID、密码转义、参数校验、配置备份和恢复、保存失败回滚。 |

v0.0.1 尚待目标真机复核软件中心上传安装、实际切换上级网络及重启后的联网。支持范围限于上表机型和环境。
