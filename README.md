# WISP 无线上网

TUF 小旋风 Pro（TUF-BE6500）在本项目使用的 57143 KoolCenter 固件界面中没有可直接开启的 WISP 模式。这套方案用 **2.4 GHz 无线接口模拟无线 WAN**。路由器通过 Wi-Fi 连接上级热点，接在本机 LAN 口或连上本机热点的设备都能借这条链路上网。

**完整包内置联网脚本。** 在适配的 KoolCenter 固件上手动安装后，从软件中心打开「WISP 无线上网」，扫描或填写上级 Wi-Fi、密码和信道，再确认保存并重启。安装本身不会改变当前上网方式。

## 实现方法

1. **同一块 2.4 GHz 无线电同时做热点和客户端。** 路由器保持「无线路由器模式」。插件的开机脚本在 2.4 GHz 无线电（`phy1`）上保留本机热点（AP），另建一个客户端接口（STA，实测名为 `wisp_sta4`）连接上级 Wi-Fi。两个接口共用一个信道，所以切换上级网络时，本机 2.4 GHz 热点也要跟着换信道。
2. **客户端接口承担 WAN 出口。** 开机脚本用 `wpa_supplicant` 完成 WPA2 认证，再由 `udhcpc` 向上级获取 IPv4 地址、网关和 DNS。插件把上级 DNS 交给固件的 `dnsmasq`，如果时钟尚未同步，就调用固件配置的 NTP 服务器校时。无线客户端接口独立于 LAN 网桥。路由器把内网设备的上网流量经默认路由转发到该接口，并用 NAT 将源地址转换为上级分配给路由器的地址。下游设备继续使用本机的内网地址。
3. **控制页管理这条连接。** 模块 `wispcontrol` 用 `ath0` 扫描附近的上级 Wi-Fi。首次保存会创建私有无线配置；以后切换网络时会保留上一份。重启后，启动项按所选网络和信道连接。页面分别检查无线认证状态和默认路由，因此能提示「已连接 Wi-Fi，但缺少上网路由」。

## 适用环境

| 项目 | 要求 |
| --- | --- |
| 机型与固件 | TUF-BE6500（TUF 小旋风 Pro WiFi 7），IPQ64。已有实机验证记录的固件为 `3.0.0.6.102_57143_koolcenter`，软件中心为 1.9.63。 |
| 工作模式 | 无线路由器模式，LAN 地址 `192.168.50.1/24`。上级 Wi-Fi 使用不同网段。 |
| 上级 Wi-Fi | 2.4 GHz，信道 1–13，WPA2-Personal（PSK / CCMP），密码为 8–63 个可打印 ASCII 字符。 |
| 固件工具 | 使用固件提供的 `iw`、`wpa_supplicant`、`wpa_cli`、`udhcpc`、`iptables`、`ip` 和软件中心接口。新安装的持久配置在 `/jffs/wispcontrol`，运行脚本安装在 `/koolshare/wispcontrol`。无线回程使用 IPv4。 |

## 安装与使用

1. 从 [GitHub Releases](https://github.com/CrayonL/wispcontrol/releases/latest) 下载附件 `wispcontrol.tar.gz`。
2. 登录路由器后台，在「软件中心 → 手动安装」上传该文件。安装完成后，从「已安装 → WISP 无线上网」打开控制页。
3. 点击「扫描附近 Wi-Fi」，选择网络、输入密码，核对信道后确认连接。打开页面、读取状态和扫描均可在当前连接下操作。确认切换、恢复、启用或停用后，路由器会保存配置并重启，通常需要约 1–2 分钟。
4. 如果新网络连不上，通过 LAN 口或本机热点重新打开控制页，点击「恢复上一份 Wi-Fi 并重启」。每次切换保留紧邻的上一份配置。若上级后来更换信道，需要重新扫描并应用。

完整包的版本为 **v0.0.1**。使用早期控制页版本的设备可手动覆盖安装；其中也有一个同名 v0.0.1 控制页包，请按发布页的 SHA-256 识别完整包。检测到已有的独立开机脚本和配置时，插件沿用该环境，避免在同一无线电上重复启动客户端。新旧配置目录同时独立存在时安装器会提示冲突。

全新安装时，插件使用软件中心的启动钩子，并在防火墙重新加载后补回转发规则。卸载独立运行的完整包会断开无线回程、还原插件使用的 DNS 设置及原热点信道配置，并移除其启动钩子；保存的 Wi-Fi 配置会保留，在重新安装后可手动启用。旧环境覆盖安装后再卸载，原有的独立开机脚本仍按原设置工作。

## 构建与验证

在 Linux 下从仓库根目录运行。打包工具来自 [rogsoft 的 build.py](https://github.com/koolshare/rogsoft/blob/f2181f4528369336382a91cec458a05371b18de3/build.py)。

```sh
python3 build.py --platform ipq64
node tests/test_control.js
timeout 60 busybox sh tests/test_control.sh
sha256sum wispcontrol.tar.gz
```

| TUF-BE6500 真机，v1.0.3 | 登录后打开控制页、读取无线状态、扫描、输入校验以及返回软件中心。 |
